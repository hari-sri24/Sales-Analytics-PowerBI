# 📊 Sales Performance & Profit Analytics Dashboard

An interactive **3-page Power BI Business Intelligence solution** built to analyze **1,500+ sales transactions** representing **₹130.7M+ in total revenue** and **₹41.36M in profit**. 

This repository showcases advanced data modeling, DAX measures, regional sales breakdowns, salesperson leaderboards, and customer segment insights.

---

## 📌 Project Overview & Highlights

- **Total Revenue Analyzed:** ₹130.72M
- **Total Profit Generated:** ₹41.36M
- **Total Order Volume:** 1,500+ transactions across 4 key geographic regions
- **Average Customer Rating:** 3.61 / 5.00

---

## 🛠️ Tech Stack & Skills

- **Business Intelligence:** Power BI (Desktop & Service)
- **Data Modeling & Calculations:** DAX (Data Analysis Expressions), Custom Measures & Calculated Columns
- **ETL & Data Cleaning:** Power Query
- **Data Source:** Microsoft Excel (`PowerBI_Beginner_to_Advanced_Raw_Sales_Dataset.xlsx`)
